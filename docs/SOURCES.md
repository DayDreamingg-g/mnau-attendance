# Sources and unresolved mappings

Проверка: 06.09.2026. Это реестр происхождения справочников и ограничений импорта, а не утверждение об официальном календаре занятий.

## Файлы и метод

| Исходное вложение | Копия | Страниц | Целевые группы |
|---|---|---:|---:|
| `1-kurs(1).pdf` | `source-data/course-1.pdf` | 3 | 5 |
| `2-kurs(1).pdf` | `source-data/course-2.pdf` | 3 | 7 |
| `3-kurs(1)(1).pdf` | `source-data/course-3.pdf` | 3 | 9 |
| `4-kurs(1).pdf` | `source-data/course-4.pdf` | 2 | 7 |

Прочитаны текст и структура таблиц всех 11 страниц, страницы отрендерены для визуального осмотра. Целевые заголовки находятся на первых страницах; на остальных проверены заголовки других направлений. Первые страницы дополнительно осмотрены в увеличенных фрагментах таблиц.

`extract-sources.py` сопоставляет геометрию таблиц и координаты заголовков групп. Дисциплина и преподаватель извлекаются только внутри конкретной ячейки (`within_bbox`), а не по соседству строк в линейном тексте. Местоположение, напечатанное возле границы ячейки, хранится также как `boundaryRaw` и `locationRaw`. Каждая SourceRecord содержит исходное имя файла, страницу, bbox, raw и структурированные данные. Имена не дополняются выдуманными инициалами. `Вакансія` становится `teacherId = null`.

Получено 411 непустых исходных ячеек; 268 имеют достаточный фрагмент для использования в **синтетической** демонстрации. Оставшиеся также сохранены для просмотра. Автоматическое распознавание всех связей не равнозначно ручному утверждению каждой записи. `usableForSyntheticDemo` означает ровно пригодность для демки; ни одна запись этим полем не сертифицируется как точный официальный календарь.

Повторить извлечение можно Python 3 с `pdfplumber==0.11.8`:

```powershell
py -m pip install pdfplumber==0.11.8
py scripts/extract-sources.py
```

Seed использует готовые JSON и не требует Python/Poppler. Исходные вложения не изменялись. Инвентаризация страниц — `source-data/page-inventory.json`; построчные неоднозначности — `source-data/ambiguities.json`.

## Принадлежность факультету

Официальные страницы подтверждают направления менеджмента, экономики, публичного управления, компьютерных наук, гостинично-ресторанного дела и туризма в структуре факультета менеджмента. Использованы [факультет менеджмента](https://www.mnau.edu.ua/faculty-men/), [компьютерные науки](https://www.mnau.edu.ua/faculty-men/opc-122-kn/), [менеджмент](https://www.mnau.edu.ua/faculty-men/opc_073_men/), [туризм](https://www.mnau.edu.ua/faculty-men/opc_242/), [гостинично-ресторанное дело](https://www.mnau.edu.ua/faculty-men/opc-241-grs/) и [кафедра публичного управления](https://www.mnau.edu.ua/faculty-men/kaf-pua/). Часть страниц временами отвечала 502; сведения сопоставлены с официальными страницами программ и результатами поиска официального домена.

«Облік і оподаткування», финансовое направление и «Психологія» из общей таблицы не включены в целевой факультет. Для них предусмотрена независимая факультетская структура; официальный источник — [обліково-фінансовий факультет](https://www.mnau.edu.ua/faculty-off/). Его студенты и занятия не засеиваются только на основании общей страницы расписания.

## Неоднозначности, которые остаются открытыми

- У разных наборов отличаются названия направлений, в частности «Готельно-ресторанна справа та кейтеринг» и «Готельно-ресторанна справа». В базе разделены варианты справочников для 1–2 и 3–4 курсов; исходные названия сохранены. Это не доказательство конкретного года набора. `intakeYear` и точное `programName` не назначены автоматически.
- Официальные страницы содержат legacy-коды 073, 051, 281, 122, 241, 242. Это справочная привязка направлений, а не подтверждённый код каждой конкретной группы по новому классификатору. `Specialty.code` оставлен `null`, пояснение — в `codeNote`. Для заполнения необходимы утверждённые учебные планы соответствующих наборов.
- `Пархоменко А.Ю.` и `Пархоменко О.Ю.` не объединены. `Богатенкова О.Є.` и `Богатєнкова О.Є.` сохранены отдельными строками; 53 преподавательские записи не означают 53 подтверждённые уникальные личности. В строках без инициалов инициалы не угадываются.
- Части ячеек без полного названия предмета/преподавателя, совместные колонки, подгруппы и чередование недель перечислены в JSON. `splitCell` и bbox сохраняют факт разделения; недостающая чётность недели не восстанавливается предположением. Точные расписания подгрупп пока не нормализованы в исполняемый календарь.
- Сокращение `кр` не приравнивается к `карп`: корпус помечен как неизвестный/требующий уточнения. Расшифровки `гк`, `м`, `карп` и расписание восьми звонков предоставлены пользователем; это явно отличено от извлечённой PDF-ячейки.
- Дата занятия в seed — синтетическая. Номера пар/слоты и размещение распределены без явных конфликтов преподавателя, группы и аудитории. Совместная demo-лекция Кн 3/1 + Кн 3/2 — один Lesson с двумя группами; она демонстрирует модель, а не подтверждает совместную лекцию в PDF.

Автоматически догадаться о неоднозначностях было бы недостаточно для официального импорта. Для университетского использования их должен разрешить владелец исходного расписания; демо уже работает без такого утверждения.
